Calculadora Simples em React JS
Sobre o projeto

Este projeto consiste no desenvolvimento de uma calculadora
simples utilizando React JS e Vite.

A aplicação permite realizar operações matemáticas básicas
a partir de dois números informados pelo usuário.

## Funcionalidades

- Inserir o primeiro número.
- Inserir o segundo número.
- Selecionar uma operação matemática.
- Realizar adição, subtração, multiplicação e divisão.
- Exibir o resultado na tela.
- Limpar os campos.
- Validar campos vazios e divisão por zero.

## Tecnologias utilizadas

- React JS
- JavaScript
- HTML
- CSS
- Vite

## Conceitos aplicados

- Componentização.
- Hooks do React, utilizando useState.
- Eventos onChange e onClick.
- Renderização condicional.
- Manipulação de estados.
- Estruturas condicionais.
- Operações matemáticas.
- Estilização com CSS.

## Como executar o projeto

1. Clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Execute o comando npm install.
4. Execute o comando npm run dev.
5. Acesse o endereço indicado no terminal.
